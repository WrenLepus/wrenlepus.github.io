Experience Highlight

Wrapped up an incredible co-op term as a Software Engineering Intern at Surestep, working on Onyx GRC, a Governance, Risk, and Compliance platform.

Over the course of this term, I got to work fullstack:

  • Backend & Data - Engineered and maintained a data pipeline processing 10M+ records, built automated Python workflows to scrape, parse, and normalize regulatory data from Canadian and U.S. sources into structured JSON, and developed API integrations to bring external regulatory data into the platform.
  • Frontend & UX - Designed and implemented 50+ React and TypeScript features, working closely with the team to refine the platform's UI/UX from concept to production.
  • AI-Integrated Development - Leveraged tools like OpenAI Codex and Claude Code to prototype and ship features faster, while learning firsthand how AI-assisted workflows are reshaping modern software development.
  • Collaboration - Worked cross-functionally with engineers and stakeholders, translating complex technical concepts into clear, actionable explanations for the broader team.

This experience pushed me to grow across the full stack - from database integration to pixel-level UI polish - and gave me a front-row seat to how AI tools are changing the way software gets built. Grateful for the mentorship and the chance to ship real, production-facing features. On to what's next!
